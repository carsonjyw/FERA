# Peer usability test (about 5 minutes)

**Goal:** can someone who has never seen FERA use it without any explanation?

## Setup

- A classmate, on their own phone or laptop, with the live URL.
- You only **watch and take notes**. Don't explain, point, or hint. If they ask "what do I do?", answer "What would you try?"
- Ask them to think out loud.

## What to say (only this)

> "This is a website about wildlife. Please try to do the tasks below. I can't help, because I want to see where it's confusing. You're testing the site, not being tested."

## Tasks

| # | Task (read aloud) | Success looks like | Time / notes |
|---|---|---|---|
| 1 | "Tell me what you think this site is for." | Says something like "search and save animals / wildlife sightings" | |
| 2 | "Create an account." | Signs up without help | |
| 3 | "Find a fox, or any animal you like." | Uses the search box or a group chip | |
| 4 | "Save one animal so you can find it again." | Clicks ♡ or "Save this animal" | |
| 5 | "Now find the animal you saved." | Opens **My Discoveries** in the header | |
| 6 | "Add a private note to it." | Uses "+ Add a private note" | |
| 7 | "Go back to exploring and save one *sighting*, a single photo someone took." | Saves from a "Sighting" card or page | |
| 8 | "What's the difference between an Animal and a Sighting?" | Roughly: a kind of animal vs. one photo/place/day | |

## Watch for

- Where did they hesitate, or click the wrong thing?
- Did they find the ♡ or the Save button without help?
- Did they find My Discoveries on their own?
- Did anything surprise them (a message, a prompt, a missing back button)?
- Did the sign-up go smoothly?

## Debrief questions (2 minutes)

1. What was the most confusing moment?
2. What would you change first?
3. On a scale of 1 to 5, how easy was it to use without instructions?
